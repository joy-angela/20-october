setting up Github repositorie for the first time

when setting up a Github repositorie for the first time you need the following steps

  • git init
  • git add.
  • git commit -m
  • git branch -M main
  • git remote origin
  • git push-u origin main

updating a Github repositorie

when updating a Github repositorie or push an existing repositorie we use the following steps

  1. git add
  2. git commit -m "message"
  3. git push
